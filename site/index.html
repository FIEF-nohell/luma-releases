Luma

Video in, point cloud out.

Luma is a Windows app that turns a video into a colored 3D point cloud. Install it with one line in PowerShell.

Install or update (PowerShell)

irm https://getluma.nohelll.com/script/install.ps1 | iex

Uninstall (PowerShell)

$env:LUMA_UNINSTALL="1"; irm https://getluma.nohelll.com/script/install.ps1 | iex
Windows 11, 64-bitPaste into PowerShell and press Enter
