Luma

Turns a video into a colored 3D point cloud. Native Windows 11 app.

Install or update, in PowerShell:

irm https://getluma.nohelll.com/script/install.ps1 | iex
  • Installs the newest build into your user folder, no administrator rights needed. The download is checked against its SHA256.
  • Needs Windows 11 (64 bit) and a GPU with OpenGL 4.5.
  • Development builds, not code signed yet: Windows may show "Unknown publisher" on first start.
  • Read the script before running it, or download a build by hand.
Uninstall: $env:LUMA_UNINSTALL="1"; irm https://getluma.nohelll.com/script/install.ps1 | iex
